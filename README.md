# 古代文献の再現も出来る夜空ビューア

古代の文献に記録された空（彗星の出現、日食・月食前後の星空、歴史上の事件の夜空）を、現代の計算で再現して文献と照合するための単一ファイルの夜空ビューアです。`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## 使い方

- **日時**：紀元前〜未来まで。1582年10月15日以降はグレゴリオ暦、それ以前はユリウス暦で入出力します。入力時刻は日本時間（UTC+9）として扱います。古代の文献の日付は、まずこの暦に直してから入れてください。
- **場所**：緯度・経度を小数1桁で直接入力するか、エリア＞場所の2段リストから選択。文献の残る地域（中東・中国・インド・欧州）は基点ごとに細分してあります。座標を入れると近くの登録地点にセレクトが連動し、「周辺」には約300km圏内の都市・遺跡が距離順に出ます（クリックで移動）。
- **空**：ドラッグで視線移動、視野スライダで拡大・縮小。星の表示等級はスライダー（1〜6等）。天の川の重ね表示つき。
- **再生**：「▶ 10分刻みで進める」で時刻が10分ずつ進みます。

## 収録データと計算

- **星**：約3,200個（5.6等まで、Yale Bright Star 系データ）。歳差を補正するので古代でも配置が合います。
- **太陽・月・惑星**：Schlyter の簡易計算法（誤差1〜2分角、時代が離れると数分角〜）。月の月齢も表示。
- **ハレー彗星**：全31出現（紀元前240年〜2061年）。出現ごとの近日点日（Catalog of Cometary Orbits / Yeomans）に、軌道要素を837年・1986年・2061年の公表値の間で内挿。1986年の位置は IHW Orbit 61 の独立伝播と約1°以内で一致を確認済み。
- **主要彗星83個**：紀元前44年カエサルの彗星から紫金山・アトラス彗星まで。軌道要素は JPL SBDB の公表値。楕円・放物線・双曲線の3ソルバー内蔵。選ぶと近日点の10日前の20時に移動し、視線が彗星を中心に捉えます。尾は全彗星共通のイメージ（青いイオンの尾＋白い塵の尾）で、長さと向きは位置計算に従います。

## 注意（精度について）

- 彗星の**明るさは推定**です。SBDB の絶対等級フィットは有名彗星のピークで実測と大きくずれる物があったため、有名どころと歴史的彗星はピークの実測に合わせた概算値を使っています。位置の方が確かです。
- 周期彗星は収録した回帰の前後でのみ正しく、古代の彗星ほど位置の誤差が大きくなります（数度まで）。
- 古代は地球の自転の遅れ（ΔT）で数時間ずれる事があります。文献の「日没時」「夜明け前」等の記述に合わせて時刻を前後させて合わせ込んでください。
- 遺跡・古代都市の座標は概略です。出典と照合済みの8地点以外には（仮）を付けています。
